# Wednesday 25 November 2026 — world news in one image

A single-page visual briefing built from the 38 verified stories in `stories.md`.

Regenerate the PNG with `python3 tools/make_image.py` (Python 3 and Pillow required).
Run the entry program with `node main.ts`; it copies `entry.png` to `$MAKEFUN_OUTPUT_DIR` or `/output`.
